# Макроквиз Live

Живая викторина для пары, похожая на Kahoot. Преподаватель показывает на проекторе экран ведущего с QR-кодом. Студенты сканируют его телефоном, вписывают фамилию и имя и отвечают на вопросы. Регистрация студентам не нужна. Проверено на 60 одновременных участниках.

- **Экран студента:** главная страница сайта, например `https://makroquiz-live.onrender.com/`
- **Экран ведущего:** та же ссылка с `/host` в конце, например `https://makroquiz-live.onrender.com/host`. Для входа нужен PIN-код.

> **Важно.** После каждой игры сразу нажимайте «Скачать результаты». Бесплатный сервер стирает свои файлы при перезапуске, и сохранённая на нём копия может пропасть.

## Как провести игру на паре

**За 5 минут до пары**

1. Откройте на компьютере у проектора адрес ведущего (`…/host`). Бесплатный сервер «засыпает», если им долго не пользуются. Первое открытие может занять 30–60 секунд, это нормально. Подождите, пока появится окно для PIN.
2. Введите PIN. Появится лобби: большой QR-код и короткая ссылка.
3. Выберите **режим**, время на вопрос (15, 20 или 30 секунд) и число вопросов (8, 12 или все).
   - **Каждый в своём темпе** (по умолчанию). Ответив, студент 3 секунды видит «Верно/Неверно» и правильный ответ, затем сразу получает следующий вопрос. Кнопка «Дальше» переключает без ожидания. У каждого свой порядок вопросов, чтобы быстрые не подсказывали соседям. На проекторе видно, кто на каком вопросе и сколько у кого баллов. Когда все закончат, игра завершится сама.
   - **Все вместе**. Все отвечают на один вопрос одновременно, вопрос и итоги показываются на проекторе. Здесь же выбирается переход к следующему вопросу: вручную или автоматически через 10, 15 или 20 секунд.

   Ниже описан режим «все вместе». В режиме «в своём темпе» после «Начать» ничего нажимать не нужно, только при желании «Завершить игру».
4. Разверните браузер на весь экран клавишей **F11**.

**Во время игры**

1. Студенты сканируют QR-код камерой телефона или вводят ссылку вручную, пишут фамилию и имя и нажимают «Войти». Их имена появляются на экране, счётчик растёт.
   - Если кто-то вписал не своё имя или шутку, нажмите крестик рядом с именем.
   - Если два студента с одинаковыми именами, второму сайт предложит добавить инициал.
2. Когда все вошли, нажмите **«Начать»** или клавишу **Пробел**.
3. Во время вопроса на экране видны таймер и счётчик «Ответили N из M». Когда ответят все, вопрос закончится сам. Чтобы закончить раньше, нажмите **«Пропустить таймер»** или **Пробел**.
4. После вопроса на экране появятся верный ответ, пояснение, сколько человек выбрало каждый вариант и топ-5.
   - Если включён автопереход, внизу идёт отсчёт «Следующий вопрос через 12 с», и вопрос начнётся сам. Чтобы задержаться и обсудить ответ, нажмите **«Пауза»**. Чтобы продолжить отсчёт, нажмите **«Продолжить»**, а чтобы перейти сразу, **«Дальше»** или **Пробел**.
   - Если выбрано «вручную», нажмите **«Дальше»** или **Пробел**.
5. После последнего вопроса появится полный рейтинг. Чтобы закончить досрочно, нажмите **«Завершить игру»**.
6. **Сразу нажмите «Скачать результаты».** Скачается файл для Excel: фамилия и имя, баллы, число верных ответов, место и отметка по каждому вопросу (верно / неверно / нет ответа).
7. Для второй игры с той же группой нажмите «Новая игра»: студенты останутся в лобби, баллы обнулятся.

**Правила для студентов**

- На ответ один шанс, изменить нельзя.
- Верный ответ даёт от 500 до 1000 баллов: чем быстрее, тем больше. Неверный ответ или пропуск дают 0.
- Время считает сервер, а не телефон, поэтому схитрить с часами нельзя.
- Если телефон заснул, закрылась вкладка или пропал интернет, достаточно снова открыть ссылку. Телефон вернётся в игру сам, а если нет, нужно ввести то же имя. Баллы сохранятся.

**Тема экрана.** Кнопка в правом верхнем углу экрана ведущего переключает светлую и тёмную тему. На проекторе в светлой аудитории обычно лучше видна светлая тема.

**Если открыть экран ведущего во втором окне или на другом компьютере**, управление перейдёт туда. Первое окно покажет надпись и кнопку «Вернуть управление сюда».

## Как заменить вопросы

Вопросы лежат в файле `questions.txt`. Одна строка — один вопрос:

```
вопрос | верный ответ | неверный | неверный | неверный | пояснение
```

- Первый ответ в строке всегда верный. На экране порядок ответов перемешивается сам.
- Пояснение можно не писать, но оно полезно для разбора.
- Пустые строки и строки, которые начинаются с `#`, пропускаются.
- Если строка оформлена с ошибкой, экран ведущего покажет её номер в лобби.

**Если сайт выложен на Render** (основной вариант):

1. Откройте свой репозиторий на github.com и нажмите на файл `questions.txt`.
2. Нажмите значок карандаша (Edit) справа вверху.
3. Измените текст: можно стереть всё и вставить свои вопросы.
4. Нажмите зелёную кнопку **Commit changes…**, затем ещё раз **Commit changes**.
5. Render сам обновит сайт за 2–3 минуты. Не делайте этого во время игры: обновление перезапускает сервер.

**Если игра запущена на вашем компьютере:** откройте `questions.txt` в Блокноте, измените и сохраните (кодировка UTF-8, в Блокноте она стоит по умолчанию). Новые вопросы подхватятся при следующем нажатии «Начать», перезапуск не нужен.

## Как выложить на Render (по шагам)

Render — бесплатный хостинг. Понадобятся два аккаунта: GitHub (там хранится код) и Render (там работает сайт).

**Шаг 1. Код на GitHub.** Если репозиторий уже создан, переходите к шагу 2. Если нет:
1. Зарегистрируйтесь на https://github.com.
2. Нажмите **+** справа вверху → **New repository**, имя `makroquiz-live`, нажмите **Create repository**.
3. На странице нового репозитория нажмите ссылку **uploading an existing file** и перетащите туда все файлы и папку `public` из этого проекта (кроме папок `node_modules` и `results`). Нажмите **Commit changes**.

**Шаг 2. Сайт на Render.**
1. Откройте https://render.com и нажмите **Get Started**. Выберите вход через **GitHub**.
2. Нажмите **+ New** (вверху) → **Web Service**.
3. Выберите репозиторий `makroquiz-live`. Если его нет в списке, нажмите **Configure GitHub** / **Connect account** и разрешите Render доступ к этому репозиторию.
4. Заполните поля:
   - **Name:** `makroquiz-live` (из имени получится адрес сайта)
   - **Language:** `Node`
   - **Branch:** `main`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** **Free**
5. Ниже, в разделе **Environment Variables**, нажмите **Add Environment Variable**:
   - **Key:** `HOST_PIN`
   - **Value:** ваш PIN, например 4–6 цифр, которые легко запомнить, но трудно угадать
6. Нажмите **Deploy Web Service**. Через 2–5 минут вверху появится зелёная надпись **Live** и адрес вида `https://makroquiz-live.onrender.com`.
7. Откройте этот адрес с `/host` в конце и проверьте вход по PIN.

PIN можно поменять в любой момент: в Render откройте сервис → **Environment** → измените `HOST_PIN` → **Save Changes**. Сайт перезапустится примерно за минуту.

## Как запустить на компьютере

Это нужно, только если вы хотите попробовать игру без интернета или без Render.

1. Установите **Node.js LTS** с сайта https://nodejs.org (кнопка LTS, далее «Next» до конца).
2. Откройте папку проекта, в адресной строке Проводника напишите `cmd` и нажмите Enter. Откроется чёрное окно.
3. Один раз выполните команду (она скачает нужные библиотеки):
   ```
   npm install
   ```
4. Запустите игру:
   ```
   npm start
   ```
5. В браузере откройте `http://localhost:3000/host`. PIN по умолчанию `1234`.
   Чтобы задать свой PIN, запускайте игру так: `set HOST_PIN=4821 && npm start`.
6. Телефоны студентов должны быть в той же сети Wi-Fi, что и компьютер. QR-код на экране ведущего уже содержит правильный адрес.
7. Чтобы остановить игру, закройте чёрное окно.

Результаты каждой игры также сохраняются в папку `results` рядом с программой.

## Нагрузочный тест

Тест изображает 60 студентов, которые проходят две игры целиком: «все вместе» и «каждый в своём темпе». Занимает около 2,5 минуты. Попутно он проверяет повторный вход после обрыва связи, ответ после таймера, дубли имён, второго ведущего и выгрузку CSV.

```
node loadtest.js https://makroquiz-live.onrender.com ВАШ_PIN 60
```

Для компьютера: `node loadtest.js http://localhost:3000 1234 60`.

Тест сам управляет игрой как ведущий, поэтому **не запускайте его во время пары**. В конце должно быть написано `ИТОГ: ВСЁ В ПОРЯДКЕ`.

## Что делать, если не работает

| Что случилось | Что сделать |
|---|---|
| Сайт долго открывается | Бесплатный сервер просыпается 30–60 секунд. Подождите и обновите страницу. Открывайте экран ведущего за 5 минут до пары. |
| «Неверный PIN» | Проверьте `HOST_PIN` в Render → ваш сервис → Environment. После 8 ошибок вход блокируется на минуту. |
| В лобби написано «PIN ведущего стандартный» | Вы не задали `HOST_PIN`. Добавьте его в Render (см. шаг 2.5). |
| Студент не может войти: «Такое имя уже есть» | Пусть добавит инициал: «Иванов Иван П.». |
| Студент случайно вошёл под чужим именем | Нажмите крестик у этого имени в лобби. Студент войдёт заново. |
| У студента пропала связь | Пусть обновит страницу. Если игра не вернулась сама, пусть введёт то же имя. Баллы сохранены. |
| Вверху экрана ведущего жёлтая полоса «Нет связи» | Проверьте интернет у компьютера. Страница переподключится сама, игра на сервере при этом продолжается. |
| Надпись «Управление открыто в другом окне» | Экран ведущего открыт где-то ещё. Нажмите «Вернуть управление сюда». |
| QR-код ведёт не туда (запуск на компьютере) | Телефоны должны быть в той же сети Wi-Fi. В сети университета это часто запрещено, тогда используйте Render. |
| Вопросы не обновились | На Render подождите 2–3 минуты после правки на GitHub и проверьте в Render раздел **Events**: последняя сборка должна быть **Deploy live**. |
| Пропали старые результаты | Бесплатный сервер стирает файлы при перезапуске. Скачивайте CSV сразу после игры. |
| Excel показывает всё в одной колонке | Откройте Excel → Данные → Из текстового/CSV-файла, выберите файл и разделитель «точка с запятой». |

## Для технически подготовленных

- Node.js 18+, Express, WebSocket (`ws`), QR-код строит сервер (`qrcode`). Внешних CDN нет.
- Переменные окружения: `PORT`, `HOST_PIN`, `PUBLIC_URL` (адрес сайта для QR-кода; на Render определяется сам из `RENDER_EXTERNAL_URL`), `QUESTIONS_FILE`, `RESULTS_DIR`.
- Игра хранится в памяти. CSV пишется в `results/` после каждого вопроса.
- Баллы: `round((500 + 500 × осталось / всего) / 10) × 10`. Ответ, пришедший на сервер позже чем через 0,3 с после конца таймера, не засчитывается. Эти 0,3 с — запас на задержку сети.
- Верные ответы уходят клиентам только после окончания вопроса.
